
# Habit Tracker 🌱

A simple and intuitive habit-tracking web application built with Vue.js.

## 🚀 Live Demo

[Try Habit Tracker](https://aya-albdewi.github.io/habit-tracker/)

## ✨ Features

- Track daily habits.
- Mark habits as completed.
- Save habits using Local Storage.
- Navigate between application pages.

## 🛠️ Built With

- Vue.js
- JavaScript
- Vue Router
- HTML & CSS
- Local Storage

## ⚙️ Project Setup

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run serve
```

Build for production:

```bash
npm run build
```
